# Boom Meat ERP · لوحة التشغيل

سيستم المخازن والتصنيع والحسابات والمبيعات لبوم ميت.

## التشغيل
- `config.js` فيه بيانات Supabase، وكل موظف بيدخل بيوزر وباسورد.
- لو `config.js` فاضي، السيستم بيشتغل ببيانات تجريبية في المتصفح. ده للتطوير بس، ومش موجود في الملفات اللي بتترفع.

## اللغة والشكل
- **عربي وإنجليزي:** زرار `EN` / `ع` فوق. الترجمة في `i18n.js` (عربي ← إنجليزي)، ولما تضيف نص جديد في الواجهة ضيف ترجمته هناك.
- **ليلي ونهاري:** زرار الشمس والقمر.
- **الاتجاه:** الصفحة كلها بتتقلب يمين أو شمال حسب اللغة.

## قرارات
- **مفيش وصفة ثابتة للمنتجات:** كل تشغيلة بتتسجل بالفعلي.
- **كود الصنف بيتعمل تلقائي حسب نوعه:** RM لحوم، SP توابل، PK تعبئة، FG منتج. وبيفضل ثابت ميتغيرش.
- **كل مورد ليه أصناف:** والاستلام منه مقصور عليها.

## إزاي النسخة الشغالة بتحمي الأرقام
- المتصفح **بيقرا بس**. أي عملية (صرف، فاتورة، قيد) بتروح للـ Edge Function `erp`، وهي اللي:
  - تتأكد من الحساب ودوره من جدول `profiles`.
  - تشغّل نفس محرك `engine.js`.
  - تحفظ بشرط الـ version، فلو اتنين حفظوا في نفس اللحظة محدش يمسح شغل التاني.
- كل طلب بيتسجل في `erp_ops`، ونسخة كاملة من الدفاتر بتتحفظ كل يوم في `erp_snapshots`.
- التسجيل الذاتي مقفول، والمالك بس اللي يعمل حسابات جديدة من "المستخدمين والصلاحيات".
- توكن تليجرام متخزن في `erp_secrets` على السيرفر بس.

## التركيب على Supabase جديد (مرة واحدة)
```bash
SUPABASE_ACCESS_TOKEN=<token> node supabase/setup.mjs https://<ref>.supabase.co
```
بيعمل الآتي:
- الجداول والصلاحيات.
- يقفل التسجيل الذاتي.
- ٦ حسابات مبدئية: owner, accountant, store, supervisor, worker1, sales.
- دفاتر فاضية فيها كل الأصناف.
- يرفع الـ function.
- يكتب `config.js`.
- يحفظ الباسوردات في `../private/boom-erp-accounts.txt`.

## بيانات المثال
```bash
SUPABASE_ACCESS_TOKEN=<token> node supabase/load-sample.mjs https://<ref>.supabase.co
```
بيملا الحسابات الحقيقية بشهر مثال (آخر ٣٠ يوم، وكل الأصناف ليها رصيد)، ومربوط بحسابات الموظفين الحقيقية. وعشان تمسحه: **الإعدادات** ← **تصفير الحسابات**، وده بيمسح كمان العملاء والموردين التجريبيين.

## الرفع
```bash
./pack-site.sh
```
بيعمل `boom-erp-site.zip`: ملفات الموقع بس. ارفعها على GitHub Pages أو Netlify.

## الاختبار
```bash
node supabase/tests/server.test.mjs
```
بيختبر الصلاحيات، والحفظ في نفس اللحظة، والمستخدمين، وتليجرام، وفي الآخر بيتأكد إن الحسابات متوازنة.

## عند كل تعديل
- زوّد رقم `?v=` في `index.html`.
- لو اتعدل `engine.js`، ارفع الـ function تاني:
```bash
cp engine.js supabase/functions/erp/engine.js
```
```bash
npx supabase@2.122.0 functions deploy erp --project-ref <ref> --use-api
```
